# 按国家分类数据：目录、字段与使用口径

本目录是总库 `指数下载工具/修复后数据` 按国家、再按联赛拆出来的副本。  
**列名、编码、盘口符号、水位、阶段、结算公式与总库相同。**  
总库里的隔离明细、Excel 分片、分盘口拆文件、校验清单和质量标记库**没有**再拆一份，需要时回总库查。

分类怎么拆、各国场次见 [分类说明](分类说明.md)。  
联赛对照见 `联赛国家对照.csv`、`各国联赛一览.csv`。  
程序用字段字典见 [schema.json](schema.json)。  
挖掘方向见 [挖掘注意/挖掘方向与样本口径.md](挖掘注意/挖掘方向与样本口径.md)。

## 2. 编码与读取

- UTF-8 BOM（`utf-8-sig`），逗号分隔，第一行表头。
- 时间列按北京时间 UTC+08:00 解释；原文没有时区，不要让本机默认时区改写。
- 为防 Excel/WPS 把比分、分数盘口当成日期，部分值写成 `="2-1"`、`="2/2.5"`。程序读 CSV 后只剥这层外壳，不执行公式。

```python
def plain(value):
    text = "" if value is None else str(value).strip()
    return text[2:-1] if text.startswith('="') and text.endswith('"') else text
```

建议按字符串读；空文本当缺失，不要填成 `0` 或 `0-0`。盘口 `0` 是合法平手，判空不要用 `if line`。pandas 用 `dtype=str, keep_default_na=False`，大文件分块或用 DuckDB / Polars。

沙滩 / 室内 / 五人制已从总库删掉，本目录同样没有。不要用「沙」「室」单字再滤一层（会误伤沙特、爱沙）。

## 3. 比赛索引（11 列）

```text
日期,sId,联赛,主队,客队,开球时间,状态,全场比分,半场比分,让球val,大小val
```

一场一行。含该国该月无报价、未完赛场次。用 `sId` 关联完整指数。

| 字段 | 含义与限制 |
|---|---|
| 日期 | 球探完场列表的归档日，也是月文件分桶键；**不保证等于开球日历日** |
| sId | 球探比赛编号，按字符串保存；不能直接当另一网站的 eventId |
| 联赛、主队、客队 | 来源显示名，无统一 ID。`(中)` 常为中立场 |
| 开球时间 | 列表时间补全年月后的 `YYYY-MM-DD HH:MM`，不是独立核实的实际开球时刻 |
| 状态 | 比赛结果：`完／推迟／腰斩／中断`。**与报价明细的「状态」不是一回事** |
| 全场比分、半场比分 | 列表事后回填，可为空或带 Excel 保护。可能是行政改判；杯赛常见 90 分钟结果，不含加时 |
| 让球val、大小val | 抓列表时的盘口快照，无时间、无完整水位，不能当初盘／收盘 |

归档日 2025-03-01、开球 2025-03-02 凌晨，仍在 `2025-03` 文件。按月统计用归档日；按距开赛做特征必须另核实际开球。

按联赛挖：直接读 `{国家}/{联赛}/{年}/`。同一级别已并进一个文件夹；杯赛单独放。`联赛` 列仍是原简称。场次与皇冠／平博覆盖见 `各国联赛一览.csv`。

## 4. 完整指数（20 列）

```text
日期,sId,联赛,主队,客队,开球时间,全场比分,半场比分,公司,盘口类型,
阶段,比赛分钟,当时比分,盘口数值,盘口中文,上水/大球,下水/小球,变化时间,状态,封盘
```

一行是一次报价状态事件（含封盘）。前 8 列是回填的比赛信息，**不是**该报价时刻的历史快照。全场／半场比分禁止进入事前特征。

| 字段 | 含义与限制 |
|---|---|
| 公司 | `皇冠` 或 `平博`。球探转载历史，不是公司直连成交记录 |
| 盘口类型 | `让球` 或 `大小球`。没有显式市场时段字段 |
| 阶段 | `赛前`／`滚球`。研究以源「状态」列为准：`早／即`=赛前，`滚`=滚球 |
| 比赛分钟 | 来源文本，如 `00`、`46`、`中场`；赛前为空。不能整列转整数 |
| 当时比分 | 当时页面显示的主−客，不是事后确认的事实 |
| 盘口数值 | 让球主让为正、主受让为负、平手为 0；大小球非负。封盘为空。**0 ≠ 空** |
| 盘口中文 | 如 `平手/半球`、`受让半球`、`2/2.5`；封盘行多为 `封盘` |
| 上水/大球 | 让球=主队水位；大小球=大球水位。主队受让时上侧仍是主队 |
| 下水/小球 | 让球=客队水位；大小球=小球水位 |
| 变化时间 | `YYYY-MM-DD HH:MM`，无秒 |
| 状态 | 源页 `早／即／滚`，不是索引里的完／推迟 |
| 封盘 | `是` 或空。空只表示该行未标封盘，不保证当时能成交 |

报价没有唯一 ID。`(sId,公司,盘口类型,变化时间)` 不是唯一键，同分钟可以有多行。文件内大致按 `日期,sId,盘口类型,变化时间` 排。不要对可见字段机械 `drop_duplicates`。

## 5. 阶段、封盘、取价

报价晚于列表开球，**不能**因此改成滚球，比赛可能延期。

定时取价：先在同一任务（`sId + 公司 + 盘口类型`）和同一阶段里，取截止时点之前最近一条**状态事件**，再看它是否封盘、数值是否有效。最新事件是封盘，该时点就没有可用价，不能退回更早开放价。不能跨场、跨盘口、跨公司前向填充。

价格观察候选：非封盘，且盘口、两侧水位都是有限数，两侧水位 > 0。这不等于当时能成交。

同分钟多行按文件保存顺序；若要在该分钟开始时决策，只用此前完整分钟。

## 6. 盘口与水位

主队让球为正，主队受让为负。  
`平手/半球` → +0.25，`受让平手/半球` → −0.25，`半球/一球` → +0.75。  
大小球 `2/2.5` → 2.25。

让球方向以**决策时点的盘口**为准：

| L | 让球方 | 让球方水位 | 受让方 | 受让方水位 |
|---|---|---|---|---|
| L > 0 | 主队 | 上水/大球 | 客队 | 下水/小球 |
| L < 0 | 客队 | 下水/小球 | 主队 | 上水/大球 |
| L = 0 | 平手，转平手主／客分支 | | | |

水位按香港净赢：水位 `w` 全赢净收益 `w`，含本返还 `1+w`。例如 0.90 对应 1.90。  
两侧水位相加不是抽水率。

滚球亚洲让球通常结算下注后该时段的比分变化；普通全场大小球按全场总进球，不要改成剩余进球。不要用「进球后让球一定变 0.25、大小球一定变 1」当清洗规则。

## 7. 结算（已核实标签之后）

设盘口 `L`，核实后的目标时段终场 `Fh, Fa`，下注时同口径比分 `Ch, Ca`。

| 市场／方向 | 结算差 `d` |
|---|---|
| 赛前让球，主队 | `(Fh - Fa) - L` |
| 赛前让球，客队 | `-((Fh - Fa) - L)` |
| 滚球剩余让球，主队 | `((Fh - Ch) - (Fa - Ca)) - L` |
| 滚球剩余让球，客队 | `-(((Fh - Ch) - (Fa - Ca)) - L)` |
| 普通全场大小球，大球 | `Fh + Fa - L` |
| 普通全场大小球，小球 | `L - (Fh + Fa)` |

整数／半球：`d>0` 全赢，`d=0` 走盘，`d<0` 全输。  
四分之一盘拆成相邻两个半球档，各半份本金。  
不能只看小数是 .25／.75 就判半赢半输，还要看方向。

全赢／半赢／走盘／半输／全输净收益：`+w, +w/2, 0, −0.5, −1`。  
ROI = 总净盈亏 ÷ 本金合计；走盘计入本金。  
推迟／腰斩／中断，以及总库里 181 场比分待核实，不进 headline 净胜和 ROI。

终场比分必须来自核验过的标签，不能无条件用 CSV 里的 `全场比分`（行政改判、杯赛加时）。已知改判例：广岛三箭—狮城水手（现场 6-1，库内 0-3）、河内公安—淡滨尼（现场 4-0，库内 0-3）。

## 8. 按国家、按联赛怎么挖

1. 按联赛挖：选定 `{国家}/{联赛}/`，只读该联赛 `YYYY/皇冠` 或 `YYYY/平博` 的完整指数。先在 `各国联赛一览.csv` 确认简称和场次，不要靠队名猜国家。
2. 按国家挖：遍历该国下全部联赛文件夹，不要把多国数据加总。排除赛果待核实时，用 `挖掘注意/比分待核实_唯一sId.csv` 按国家过滤。
3. `国际赛事`、`友谊赛` 不是单一国家；其中各杯赛、球会友谊、国际友谊已按简称分文件夹，单独做方案，不要并进西班牙／巴西等目录。
4. 皇冠、平博分开挖，不要把两家净胜加总再排名。
5. 同一 `sId` 的训练／验证／测试必须落在同一集合，两家公司、两个盘口一起走。
6. 决策只用截止时点之前能看到的字段。全场／半场、后来行政比分不当事前特征。
7. 月份按索引**归档日**的自然年、自然月。当前数据到 2026-08-31。

质量标记和研究读取器仍在总库：`指数下载工具/research_data.py`、`修复后数据/研究辅助/`。按国家 CSV 没有单独再做一份质量库；需要等待规则或赛果提示时，用 `sId + 公司 + 盘口` 去总库查。

更细的年份补丁、隔离原因、滚球同步核验仍以总库 [数据结构说明](../指数下载工具/修复后数据/数据结构说明.md) 为准。
