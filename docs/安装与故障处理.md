# 安装与故障处理

当前Windows x64主机使用Python 3.12.8；当前修复与测试范围见随包 docs/当前交付范围.md。不是免依赖exe。应用源码使用Python 3.11—3.13；当前本机实测3.12.8；原v0.3.0容器记录为3.13.5。锁定numpy 2.3.5、numba 0.65.1、llvmlite 0.47.0。

## 首次双击

`启动工作台.bat` → 调用`setup_windows.ps1` → 优先选择本机Python 3.11—3.13 x64；缺少时下载官方Python 3.13.15并核对哈希至runtime → 创建.venv → PyPI安装锁定包 → 运行单元测试 → 启动本机网页。脚本的ExecutionPolicy Bypass只作用于这次进程，不设置系统长期执行策略。未请求管理权限，不修改系统PATH；Python安装器可能写入当前用户的安装记录。

仅设置阶段联网，比赛数据不上传。软件不是ChatGPT内运行，计算花费本机CPU/内存/磁盘，不消耗任何模型API配额。首次Numba编译可能等待，之后使用本机编译缓存。

## 常见情况

**网页没有打开：**查看终端显示的本地网址；默认`http://127.0.0.1:8765`，复制到浏览器。不能把这个地址给其他电脑当云服务。

**端口被占用：**确认是否已经开过一个工作台。不要同时启动两份服务操作相同workspace。命令行可以改端口，但应关闭原服务先。

**下载失败：**检查能否访问Python官网和PyPI。不建议盲目执行不明镜像的一键脚本。已有Python时用`start_existing_python.bat`，仍需首次安装依赖。网络失败不应删除原数据或workspace。

**已有.venv但依赖没装完：**重新运行启动入口，会检查依赖版本，不符合就继续设置。若环境损坏，只删除程序自己的.venv（不要删workspace），然后重新启动。

**输入没有发现文件：**仅支持中文结构说明定义的CSV/目录/ZIP。需解压完整目录，不要选择只有成绩表、提示词或照片的目录。其他编码不自动猜成UTF-8，先确认数据源。

**解析失败/跨文件顺序不明：**不要年文件和其来源月文件一起导入，或母库和副本一起导入。不要把另一家公司的同一场报价当重复行删掉，按公司分别研究。

**运行耗时：**标准、常规及扩展均执行实际枚举或有证明的覆盖，可长时间计算；没有承诺任何CPU上几分钟完成。页面进度是当前方向已提交表达/冻结字典表达，不是整个S0—S7的完成比例。不要将合成演示速度外推到三年全量。

**暂停慢：**在协作检查点停止；输入、引擎自检、回放和打包均检查暂停，系统调用本身不保证即时中断。保留窗口和workspace。已提交方向特征缓存可复用；标准搜索、候选复核和组合比较分别有游标。特征生成尚未提交部分会重新生成，打包子进程可停止，恢复会重新验证未完成包。

**进程崩溃/电脑重启：**重新启动工作台，原运行任务将显示中断；点击继续。若代码/输入哈希改变，会拒绝混用。原任务需要原版代码；新版本新建任务。

**观察名单为0：**先看全部候选表和方向审查原因。0条不一定是程序失败；也不能把门槛降低到出现收益就冒称验证通过。

**已完成但显示PARTIAL_CORE：**查看workflow_status.json中未通过的门禁。旧有限规格完成、标准搜索完成、全池筛选完成和交付完成是不同状态；预算/输入缺口必须补足，不能仅修改显示文字。

**卸载：**先暂停任务并退出服务，保存需要的结果，然后删除本软件目录。runtime是本地Python安装，可通过其官方卸载方式移除当前用户安装记录；此包不是Windows注册式产品安装器。


## v0.3.1 大目录与单联赛使用

23列合并指数可直接使用，不要求重新提供已删除的索引。总目录扫描有逐文件进度与内容哈希缓存；扫描完成后单选一个实际联赛，文件名简称只作导航。任务只载入相关文件。系统默认3.14时，脚本会从py启动器登记的版本中查找受支持的64位解释器。

取消扫描保留已完成文件缓存；再次检查仍核对内容哈希。部分结果不提供重复放大预算的续跑按钮，调整设置后新建任务。若因掩码预算暂停，本版界面也应使用提高预算后的新任务，不能修改原配置冒充相同研究。


## 环境与换机

| 项目 | 口径 |
|---|---|
| 当前开发验证 | Windows x64 / Python 3.12.8 |
| 支持解释器 | Python 3.11—3.13 x64 |
| 无兼容解释器时的安装器 | 官方Python 3.13.15，核对固定SHA-256 |
| 3.13.5记录 | 旧容器历史记录，不是当前主机版本 |

换机使用白名单源码快照，重新建立.venv，不复制本机.venv或桌面快捷方式。解压后双击该目录的启动工作台.bat。源码快照用 `python -B build_source_release.py --output dist/FootballStrategyLab_source.zip` 生成；不会运行研究，也不颁发策略或完整标准验收证书。旧0.4.0源码包和证书保持原始内容。

迁移B审计包原始输入：`python -B app.py import-audit B_本次研究审计包.zip --workspace 新工作区`。按包内SHA核对并建立新的暂停任务，不访问旧机器绝对路径，也不继承旧搜索覆盖或证书；重复导入不重复创建同引擎任务。分区训练包不会被自动改成全库研究。原A交接包仍用于离线触发复验，二者用途不同。

本机registry中的绝对路径记录本机任务及原始来源，不是可任意换机复用的搜索断点。不能通过全仓替换路径、版本号或engine_hash，把旧断点伪装成新版计算。

浏览器主会话令牌由服务进程生成，不写入项目配置或访问日志；下载用短期单次票据，避免把主会话令牌放到URL。关闭界面服务不会替代暂停研究；当前用户要求不试跑时，保持任务和自动跟进暂停。

安装器先按 installer.lock 校验并固定 pip 26.2.1，再按 requirements.lock 校验计算依赖。界面的“关闭界面服务”按钮用于退出后台界面；若要停止计算，先对任务点暂停。
