# v0.4 功能与验收范围（历史文档）

> 本文保留 0.4 版口径，仅供追溯：其中的默认完整 W/C/T 网格、STANDARD_HANDOFF_COMPLETE 与 A_标准研究触发交接包、validation/本版实际验收状态.json 都不是当前默认行为。当前默认目标、完成状态与交付范围以 README_先读.md、docs/当前交付范围.md 和 docs/核心指导思想与产品目标.md 为准。

软件按单联赛、单公司自动推进S0—S7。默认standard覆盖原v3规定的有限语法；旧routine/expanded/smoke保留作有限范围研究或功能检查。功能已接入不代表某个真实联赛已经完成全部计算，实际版本验收见validation/本版实际验收状态.json，每项研究的完成门禁见workflow_status.json。

| 环节 | 当前实现与证据入口 |
| --- | --- |
| 输入 | 20列加索引、23列合并年文件、目录与ZIP；内容哈希、源质量清单、实际CSV联赛名隔离 |
| 特征 | 一次因果扫描生成16方向缓存；绑定窗口、当前球队/历史角色、严格前一完整分钟跨市场、冻结赛前摘要、连续/可插入及复合路径 |
| 搜索 | 完整W/C/T规定网格，M00—M07表达索引；历史掩码精确缓存、零交集与完整事件收益上界证明；全部净收益>10家族可逆保留 |
| 全池复核 | 家族基础成绩、逻辑规范化、历史签名、逐规则单项/联合扰动、压力、低样本与高风险分类、全部已登记盈利签名组风险比较 |
| 名单 | 分方向代表与主/较低风险组合，固定多起点加入/替换/移除；不设N最低配额，不宣称数学全局最优 |
| 触发 | 标准JSON协议、无终场标签的逐条触发、具体条件证据、首信号、保存/恢复、逐条正例/封盘负例和临界样例 |
| 自动模拟 | SQLite事务预占与回执；完整批次幂等、核心方向共享名额、整场上限、未知/部分成交、过期与缺历史报警、比赛结束封存；第二笔仅影子 |
| 评测 | 冻结名单后评测；历史滚动每个截点重新挖掘与选择；共同比赛日块重采样明确为条件诊断 |
| 交接 | A自包含开发包、B全量研究审计包；实际ZIP解压测试、最终文件哈希、S0—S7与M00—M08账、联赛总注册表 |

完整搜索、全池复核、非空名单与其余标准门禁全部通过，才生成A_标准研究触发交接包.zip并标STANDARD_HANDOFF_COMPLETE。空名单核对只能证明空链路通过；预算、数据、名单或交接缺口保留部分状态与观察包，不通过反复续跑偷偷增加预算。前期两份空名单标准完成声明已经撤销，原始ZIP与哈希保留并附失效声明。

E01—E04额外搜索、独立未来证据、公司行情/下单接口、跨联赛账户风险层均单独列出；当前没有真实资金执行资格。已给出的三年历史不能自行改称未见数据。原0.3/0.3.1日志及开发中记录属于历史证据，不能单独认证当前版本。
