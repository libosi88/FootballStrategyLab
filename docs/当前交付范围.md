# 当前交付范围（0.7.0）

产品目标以 [核心指导思想与产品目标](核心指导思想与产品目标.md) 为准。默认进行全历史稳定高净胜策略研究，不再以未来预测或样本外确认作为本次历史完成条件。

本版实现全部选定历史、16方向、按冻结最低净胜收集盈利池（默认10单位，可调）与可逆表达记录；第一阶段不提前按稳定性裁剪。第二阶段按历史跨度、主要研究段净胜、样本、回撤与集中度筛选（连亏只作报表列）；按历史原价（剔除进球前拒单的不可成交报价）选择组合，附加压力指标独立披露。

历史模式默认不做逐规则扰动和全池两两风险对照，可显式开启；不因此改变盈利池或历史资格。非空与空名单均有准确的历史完成状态，剩余覆盖与交接缺口另行记录。

新增离线按联赛生成多机分配计划，校验软件/计划/输入哈希，导入独立工作区并去重。A/B触发交接包新增联赛接入清单，记录规则、单位、执行政策、触发入口与回放依据。

0.6.1 面向正式使用补充：组合搜索不设改动与评价次数上限，按场增量重放（与逐单完整回放逐场相同）；空白滚球比分按最后已知比分判断是否进球；0.6.0 界面保存的组合上限不再带入新任务；代码更新后旧引擎任务暂停而不失败，可批量重建与续跑；多机计划列出每台机器需复制的文件，并按软件引擎、联赛、公司、输入与配置识别任务；数据检查跳过“_”开头的备份文件夹，拒绝同一联赛的重复目录。

0.6.2 只为组合比较提速，结果不变：邻域只排序一次，访问记录按规则编号比较，已达整场上限的比赛在替换时直接沿用结果，暂停标记每半秒读取一次。

0.6.3 历史模式盈利池最低净胜改为可调，默认10单位；0仍表示净胜>0全收。留出期仍然禁止。已开跑任务继续使用其冻结门槛。

0.6.3 定稿同时修复四个交付可靠性问题：滚球比分变化后的陈旧盘口/水位报价会被质量隔离；索引空白结果字段不会覆盖报价文件已有完整标签；历史界面预览改用实际历史决策的情景4；标准搜索候选验证按任务实际后端执行。对应单元、冻结回归、空/非空16方向合成流水线、依赖与真实 Chromium 界面验收均保留独立证据。

0.7.0 新增中等搜索规格 `balanced_v1`：核心原子扩到三条件，补充必要水位/盘口模板、同盘水差与1至3步投影路径及上下文；不含时限路径，M04 标 NOT_APPLICABLE，不能算作已搜索。同时改为四项默认历史政策：研究段按固定日历年划分（可选固定365天冻结锚点，旧的最后比赛日锚点保留给验证模式）；小段已发生亏损默认阻止该规则进入稳定主名单；小段正收益但成交少于5场只记证据不足，不当作已证明稳定；有终场比分但缺完场状态的比赛默认隔离，可显式改为仅标签试算或声明文件级完场契约。组合按实际派单复核分段、场次与历史跨度，另输出主备实际风险比较与可选的互补逐对研究（不改主名单，不是执行批准）。进球前拒单口径写明为代理假设 `explicit_live_close_and_score_change_within_one_minute_v2`：要求后续1分钟内同市场出现明确封盘且比分改变，空白滚球比分不算进球证据，没有真实回执。以上条件在任务开始前选择、开跑后冻结，已开跑任务继续使用其冻结政策。
