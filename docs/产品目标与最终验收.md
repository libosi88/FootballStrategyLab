# 产品目标：数据进去，明确名单与交接包出来（历史文档）

> 本文保留 0.4 版口径，仅供追溯：“未见数据与成交证据足够”和 STANDARD_HANDOFF_COMPLETE 已不是当前默认全历史研究的完成条件。当前产品目标与完成状态以 docs/核心指导思想与产品目标.md 和 README_先读.md 为准。

用户无需再逐阶段指挥模型，也不需要从几十万条候选中自行挑选。

目标操作：选择一个联赛的三年完整指数→核对数据源一次→选择固定研究配置→开始→软件自动推进输入核对、规则枚举、净胜池冻结、各方向稳定与收益筛选、非冗余组合、明确名单、触发验收和两类交接包。

结果页必须给具体名单，而不只是候选数量：各方向保留谁、多少条、净胜/回撤/连亏、样本覆盖、压力与替代、加入组合的价值，以及对应机器规则和触发包。首单/第二笔资格均须可编码，不要求每场人工判断。

同一套程序服务不同联赛；旧38条只是固定迁移回归，不能当作其他联赛固定答案或限制新的发现方向。N不凑数，完整搜索后无达标者是合法结果。不能承诺数据一放进去就必然出现未来盈利策略。

验收四件事分开：规定空间真的搜完；已选名单有筛选/替代依据；触发程序逐笔正确；未见数据与成交证据足够。程序运行通过不替代另外三项。

v0.4在原项目中接入standard规格、全池复核、确定性触发和持久化自动模拟。当前软件版本验收与具体联赛实际完成状态分别记录；只有本联赛全部声明搜索、复核、触发和自包含交接验收均通过，才写STANDARD_HANDOFF_COMPLETE。运行不调用模型API；计算消耗本机资源。
