# FootballStrategyLab

足球策略历史研究工作台，当前源码版本为 0.7.0。
使用说明见 [README_先读.md](README_先读.md)，当前功能见 [0.7.0 使用与验收入口](docs/0.7.0_使用与验收入口.md)。

## 安装与启动

Windows：双击 `启动工作台.bat`，按提示安装受支持的 64 位 Python 3.11—3.13 及锁定依赖。
Linux：参考 `start_linux.sh` 和原始使用说明。
原始比赛数据需在本机另行准备，运行时选择数据目录。

如需合成演示数据，在项目目录运行：
`python demo/generate_demo.py`
生成的 CSV 为人工合成，已被 Git 忽略，不代表真实策略收益。
